# Tibolution 2.1.0

Turn up the reasoning. Evolve the Tibo.

Tibolution is an unofficial, model-agnostic background patch for Codex Desktop.
It maps the final native reasoning effort to six local backgrounds without
editing official minified React bundles or adding unsupported effort levels.

## Highlights

- Native `low`, `medium`, `high`, `xhigh`, `max`, and `ultra` image mapping.
- One model-independent state source for every current and future model.
- Main slider and Advanced menu support through
  `data-selected-reasoning-effort`.
- Centered full-screen cover layers with a 560ms crossfade, light/dark theme
  readability, click-through behavior, and reduced-motion support.
- Streamed cross-platform ASAR rebuild with package, CSP, source immutability,
  official JavaScript hash, ASAR metadata, and unpacked companion verification.
- Exact SHA-256 backups, guarded atomic install, rollback, and exact restore.

## New in 2.1.0

Linux users can install an optional per-user application-menu launcher:

```bash
bash scripts/install-linux-launcher.sh
```

Before each menu launch it checks whether a Codex package update cleanly removed
Tibolution. If so, it rebuilds against the new official archive, runs every
compatibility check, requests visible Polkit authorization for the guarded
transaction, confirms the result, and starts Desktop.

It never silently escalates. Build failure, an incompatible client, a partial
patch, cancelled authorization, or a post-install check failure cannot block
the official client from starting. Existing user `chatgpt.desktop` content is
backed up with an exact SHA-256 and restored only when the installed override
has not been edited.

Remove the optional launcher with:

```bash
bash scripts/uninstall-linux-launcher.sh
```

## Install

Requirements: Node.js 22.12 or newer, npm, and an eligible Electron installation
of Codex Desktop. Completely exit Desktop before patch installation.

```bash
npm ci
npm test
npm run inspect
bash scripts/install.sh
```

Windows PowerShell, unpackaged installation only:

```powershell
npm ci
npm test
npm run inspect
& .\scripts\install.ps1
```

Read the complete [README](../../README.md) and platform table before installing.

## Known limitations

- Linux automatic repair applies only to application-menu launches through the
  installed user-level desktop entry.
- Immediate app-managed restarts after an update can defer repair until the next
  menu launch.
- Windows and macOS still require published real-device verification on an
  eligible unpackaged or unsigned installation.
- A future Codex frontend, CSP, or package-layout change can cause compatibility
  checks to refuse installation until Tibolution is updated.
