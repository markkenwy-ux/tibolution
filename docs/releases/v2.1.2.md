# Tibolution v2.1.2 — Desktop release candidate

本次更新重点为 Windows 运行中检测、macOS 签名保护和浅色阅读表面调整。
当前作为候选版提供；存在未解决的暗色条带问题，完整视觉验收尚未完成。

## 更新内容

- 修复 Windows Program Files、自定义路径与未知路径的运行中客户端漏检。
- macOS 仅允许确认未签名的应用；拒绝 ad-hoc、签名损坏及状态不明。
- 浅色主题移除全屏白色遮罩，为原生聊天内容区域添加局部浅色阅读底。
- 暗色主题、六张背景、推理强度映射和切换动画保持不变。
- 不自动修改 Desktop 原生主题偏好，由用户选择浅色、暗色或跟随系统。
- 仅更新 Desktop，不包含 CLI 适配项目。

## 支持边界

- Linux 有历史实机验证；本次浅色调整仍待当前客户端视觉验收。
- Windows 非商店 Electron 与 macOS 确认未签名应用为实验性支持。
- 不支持 Windows Store/MSIX 或 macOS 已签名应用，不绕过系统签名保护。
- 自动测试不能代替 Windows/macOS 真实客户端安装、重启及恢复验证。

## 已知问题

- 用户提供的当前实机局部截图显示两条明显的水平暗色边界。对照原图未发现对应
  水平黑线，可能与界面背景叠层有关，但尚未通过实时 DOM 确认具体来源。
  本候选没有修复这一问题，也不能确定它是否由 2.1.2 引入。
- 浅色、暗色、长对话、菜单、窗口缩放及六档切换的完整实机验收尚未完成。
- 本版本不包含自动切换暗色功能，也不会覆盖用户原生主题选择。

## 发布前检查

- 本地运行 npm test、Shell 语法检查及打包检查。
- 将 Git 历史与远端同步，保留本地改动；不要强制推送。
- 对本次提交和 v2.1.2 标签运行三平台 CI。
- 实际客户端检查浅色/暗色、长对话、输入框、菜单和窗口缩放。
- 完成前作为候选包使用，不宣称正式发布或全平台实机验证通过。
