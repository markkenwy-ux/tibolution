# Tibolution 2.1.1

Turn up the reasoning. Evolve the Tibo.

Tibolution 2.1.1 is a CI and cross-platform correctness release. It keeps the
2.1.0 runtime behavior while fixing the release-gating failures found by the
Ubuntu, macOS, and Windows GitHub Actions matrix.

## Fixed

- Linux launcher tests now run only on Linux hosts.
- Linux launcher installer tests provide an isolated fake `pkexec`, so they do
  not depend on the runner's installed Polkit packages.
- Windows atomic replacement gives `File.Replace` a real sibling backup path
  instead of a null path. A backup created during a failed replacement is
  retained for recovery.
- Simulated macOS discovery always builds POSIX paths, including when the test
  itself runs on Windows.
- The publishing guide now requires the tag-triggered CI run to pass before a
  GitHub Release is created.

## Verification gate

Before publishing this release:

```bash
npm ci
npm test
npm pack --dry-run --json
bash -n scripts/*.sh
```

The `main` and `v2.1.1` GitHub Actions runs must both complete successfully
on Ubuntu, macOS, and Windows. Linux runs all 47 tests; macOS and Windows skip
the nine Linux-only launcher tests while running the remaining 38 tests.

## Platform scope

- Linux Debian package: real archive, install, restore, UI, and launcher
  verification.
- Windows unpackaged Electron: automated builder, path, transaction, and
  atomic-replacement coverage; real-device verification remains pending.
- Windows Store/MSIX: intentionally refused.
- macOS unsigned/ad-hoc bundle: automated builder and transaction coverage;
  real-device verification remains pending.
- macOS valid signed bundle: intentionally refused.

Tibolution remains unofficial and does not bypass operating-system package
signatures or redistribute official Codex application files.
