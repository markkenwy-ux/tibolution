# v2.2.0-cdp.2 — Windows CDP preview

本次为原项目的预览更新，新增 Windows 官方 MSIX 客户端的 CDP 运行时注入路线，保留原有 ASAR 后端。

- 新增启动、状态检查、移除及后台守护脚本；不修改官方应用文件。
- 校验本机回环监听、官方客户端进程和主窗口，支持安装目录 Junction。
- 验证时等待原生控件稳定出现，修复页面切换造成的暂时性验证失败。
- 修复预览与原生同步、重复注入和移除清理；缺失运行时可由守护进程恢复。
- 调整聊天区及输入框透明度，让背景可见并保留文字不透明度。
- 删除旧 Windows ASAR 安装入口，首页统一引导至 CDP；保留旧补丁恢复脚本。
- 版本号统一为 `2.2.0-cdp.2`。

## 验证范围

Windows 客户端 `26.911.7940.0`：原生 medium 状态同步、六图合成预览、移除、重复注入及守护恢复通过，官方 ASAR 哈希未改变。深色聊天区透明度已实机检查。

自动测试 58 项：49 项通过，9 项 Linux 专用测试在 Windows 跳过。另有浏览器明暗主题夹具验证。合成预览不等同于原生档位交互测试；浅色主题实机验收、全部原生档位操作和客户端更新后的恢复尚未验证。

## 使用

解压源码包，安装 Node.js 22.12 或更新版本。保存工作并完全退出 Codex，然后在项目目录的 PowerShell 中运行：

```powershell
& .\scripts\start-windows-cdp.ps1 -Watch
```

停止及恢复说明见 [Windows CDP 文档](../windows-cdp.md)。CDP 调试接口仅绑定本机回环；完全关闭调试端口需要退出客户端后正常启动。此版本不是 MSIX 安装包，也不安装开机启动任务。
